## The role

Build the backend for automated restaurants using Elixir, OTP and Phoenix. Coordinate order fulfilment, robotic hardware and cloud services through distributed systems, PostgreSQL and WebSockets.

Based in Charlestown, Boston. At least three days a week in the office, with more when projects require it. Boston salary range: $176,000-$183,500.

Requires five or more years building production distributed systems, proficiency in Elixir and PostgreSQL, and experience with messaging APIs and infrastructure as code. This is robotics backend work, not a fully remote web role.
