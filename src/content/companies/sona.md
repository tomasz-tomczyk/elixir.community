Sona builds workforce-management software for frontline businesses, covering scheduling, payroll, HR and staff engagement.

Its product engineers use Elixir to deliver features across these areas. AI coding tools are part of the engineering workflow, with engineers responsible for architecture, reviewing generated code and getting features into production.
