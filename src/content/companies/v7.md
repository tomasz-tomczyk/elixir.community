## How V7 uses Elixir

V7 used Phoenix for the API behind its computer-vision platform and Elixir with Cowboy to coordinate machine-learning workers. Python nodes connected over WebSockets and reported their available resources.

For tasks such as image annotation, Phoenix put work onto RabbitMQ. The orchestrator selected an available Python node and sent it instructions, keeping data management and job coordination separate from model execution.
